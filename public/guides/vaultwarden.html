1 Your Server Connection URL

Every official Bitwarden application (iOS, Android, Chrome/Firefox extensions, desktop apps) connects using this single URL:

https://tinarchy.tail3dee69.ts.net:8000
💡 Zero Plaintext Exposure: Your master password and decrypted credentials never touch this server or network. All encryption happens client-side on your device before transmission. Even with full access to the server disk, credentials cannot be decrypted without your master password.
🔒 Private Tailscale Mesh: Vaultwarden is strictly bound and isolated to your encrypted Tailscale network (100.64.0.0/10). Make sure the Tailscale app is connected / active on your phone or laptop whenever you sync or log in.

2 Step-by-Step Client Setup

Select your platform below to connect the official Bitwarden client:

1
Install Bitwarden App:

Download the free official Bitwarden Password Manager from the Apple App Store or Google Play Store.

2
Tap Settings Gear Icon:

On the app's initial login screen, locate and tap the ⚙️ Settings gear in the upper corner.

3
Set Server URL:

Under Environment URL (or Server URL), paste your server address:

https://tinarchy.tail3dee69.ts.net:8000

Tap Save in the top corner to apply.

4
Create Account & Master Password:

Tap Create Account. Choose a strong master password (and master password hint if desired). This key derives your AES-256 vault encryption key.

5
Enable Autofill & Biometrics:

In the Bitwarden app settings: enable Unlock with Face ID / Fingerprint and enable Auto-fill Service in iOS / Android system settings.

1
Install Browser Extension:

Install the Bitwarden extension for Google Chrome, Brave, Mozilla Firefox, Apple Safari, Microsoft Edge, or Arc.

2
Configure Self-Hosted Environment:

Click the Bitwarden extension icon in your toolbar. Before logging in, click the ⚙️ Settings gear at the top left of the popup.

3
Paste Server URL:

In the Server URL field, paste:

https://tinarchy.tail3dee69.ts.net:8000

Click Save.

4
Log In & Auto-fill:

Log in with your master credentials. Use Ctrl+Shift+L (or Cmd+Shift+L on Mac) on any login page to instantly auto-fill credentials.

1
Install Desktop Client:

Download the Bitwarden desktop client from bitwarden.com/download or via your package manager (e.g. pacman -S bitwarden or Homebrew).

2
Set Self-Hosted Server URL:

On the desktop login screen, click the Settings / Gear icon (or File ➔ Settings) and paste:

https://tinarchy.tail3dee69.ts.net:8000
3
Biometric Unlock & Integration:

Enable Touch ID, Windows Hello, or Polkit biometrics in desktop app settings. You can also integrate the desktop client with browser extensions for system-wide biometric approvals.

1
Export from Your Existing Password Manager:

Export your passwords to a CSV or JSON file from Chrome, 1Password, LastPass, Dashlane, KeePass, or Apple iCloud Keychain.

2
Open Vaultwarden Web Vault:

Open https://tinarchy.tail3dee69.ts.net:8000 in your browser and log into your account.

3
Import Data:

Navigate to Tools ➔ Import Data. Select your file format (e.g. "Chrome (csv)", "1Password (1pif/csv)", or "LastPass (csv)"), select your exported file, and click Import Data.

4
Secure Clean-Up:

Remember to permanently delete (or shred) the unencrypted exported CSV/JSON file from your downloads folder!

3 Free Built-in 2FA / TOTP Authenticator

Unlike standard Bitwarden which locks TOTP behind a paid tier, Vaultwarden provides built-in 2FA code generation completely free:

🔐 How to use built-in TOTP:
1. When enabling 2FA on any website (GitHub, Google, Amazon), copy the secret key or scan the QR code with Bitwarden.
2. Bitwarden automatically generates rotating 6-digit codes every 30 seconds.
3. When auto-filling credentials on your browser or phone, Bitwarden automatically copies the 2FA code to your clipboard so you can paste it instantly without opening an authenticator app!
