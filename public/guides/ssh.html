1 Quick Connect via Terminal

Connect instantly with Tailscale SSH. No SSH keys or passwords required:

tailscale ssh pineapple@pineapple-station

2 Keyless Authentication (Zero Config)

Tailscale SSH manages authentication and ephemeral encryption keys automatically. Your terminal session verifies against your Tailnet identity without managing ~/.ssh/authorized_keys.

Web Browser Terminal: You can also SSH into this machine from any web browser without opening a local terminal by visiting the Tailscale Machines Console and clicking SSH... next to pineapple-station.

3 VS Code Remote - SSH Setup

Develop directly on the server inside VS Code using the official Remote - SSH extension. Add this block to your local ~/.ssh/config:

Host pineapple-station HostName pineapple-station.taildb42a2.ts.net User pineapple Port 22 IdentityFile ~/.ssh/id_ed25519 ServerAliveInterval 60

Then open VS Code ➔ press Ctrl+Shift+P ➔ type Remote-SSH: Connect to Host... ➔ select pineapple-station.

5 Persistent Background Sessions (Zero-Risk Disconnects)

Interactive SSH logins automatically attach to a persistent tmux session. If you close your terminal window on another PC, lose Wi-Fi, or put your laptop to sleep, your running commands, build scripts, downloads, and servers will never be killed.

🛡️ Zero-Risk Disconnects

Close your terminal anytime. The background daemon preserves all processes. When you reconnect, you land right back where you left off.

⚡ Reconnect Instantly

Simply run tailscale ssh pineapple@pineapple-station again from any device to re-attach immediately.

🔒 Systemd Linger Active

User process lingering is active (Linger=yes). The kernel never terminates background jobs upon logout.

Helpful Keyboard Shortcuts:

Detach Session: Ctrl+b d
New Window: Ctrl+b c
Next / Prev Window: Ctrl+b n / p
Mouse Scrolling: Enabled (Wheel/Trackpad)

Note: Non-interactive commands (e.g. tailscale ssh pineapple@pineapple-station ls) and file transfers run directly without tmux. To bypass tmux in an interactive shell, connect with NO_AUTO_TMUX=1.
