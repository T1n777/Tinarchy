1 Quick Connect via Terminal

Select your connection method below, then paste the command into your terminal (macOS Terminal, Linux Bash/Zsh, Windows Terminal or PowerShell):

ssh pineapple@pineapple-station.taildb42a2.ts.net

2 Setup Passwordless SSH Keys

For seamless login without typing your password every time, copy your local machine's public key to the server authorized keys:

A
Linux / macOS (One command):
ssh-copy-id -i ~/.ssh/id_ed25519.pub pineapple@pineapple-station.taildb42a2.ts.net
B
Windows PowerShell:
type :USERPROFILE\.ssh\id_ed25519.pub | ssh pineapple@pineapple-station.taildb42a2.ts.net "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
C
Don't have an SSH key yet? Generate one on your computer:
ssh-keygen -t ed25519 -C "laptop-key"

3 VS Code Remote - SSH Setup

Develop directly on the server inside VS Code using the official Remote - SSH extension. Add this block to your local ~/.ssh/config:

Host pineapple-station HostName pineapple-station.taildb42a2.ts.net User pineapple Port 22 IdentityFile ~/.ssh/id_ed25519 ServerAliveInterval 60

Then open VS Code ➔ press Ctrl+Shift+P ➔ type Remote-SSH: Connect to Host... ➔ select pineapple-station.

4 Mobile Access (iOS / Android)

To connect from your phone or tablet using apps like Termius, JuiceSSH, or Prompt:

1
Connect to Tailscale: Open the Tailscale app on your mobile device and make sure it is connected to the same tailnet.
2
Add New Host: Set Host to 100.112.193.54 or pineapple-station.taildb42a2.ts.net, Port: 22, Username: pineapple.
