Beeper Bridge Manager (bbctl)

Self-hosted Matrix chat bridges for WhatsApp, Telegram, Signal, Discord, Google Messages, and Slack. All encryption keys, local session databases, and media downloads stay directly on your server.

1 Beeper Server Authentication

Before launching bridges, authenticate your server with your Beeper account. Run this once from your terminal:

beeper login

Enter your Beeper email when prompted. Beeper will send a login confirmation code to your email.

beeper whoami
💡 Self-Hosted Encryption & Privacy: Unlike cloud-hosted bridges, self-hosted bridges via bbctl establish encrypted Matrix appservice websockets directly from your server. WhatsApp and Signal session keys never leave this physical machine.

2 Activate Bridges by Platform

Select your chat platform below for 1-click terminal commands and bot pairing steps:

1
Enable & Start WhatsApp Bridge Service:

Starts the official mautrix-whatsapp daemon in the background with auto-restart on boot:

sudo systemctl enable --now bbctl@sh-whatsapp
2
Open Beeper App & Pair QR Code:

In Beeper (mobile or desktop), search for and message @whatsappbot:beeper.local.

Send the message: login. The bot will send you a QR code.

3
Scan with WhatsApp on Your Phone:

On your phone, open WhatsApp ➔ Settings ➔ Linked Devices ➔ Link a Device, and scan the QR code in Beeper.

1
Enable & Start Telegram Bridge Service:
sudo systemctl enable --now bbctl@sh-telegram
2
Message the Telegram Bot in Beeper:

In Beeper, message @telegrambot:beeper.local with:

login +1234567890

Replace with your international phone number. Enter the Telegram login code when asked.

1
Enable & Start Signal Bridge Service:
sudo systemctl enable --now bbctl@sh-signal
2
Pair Signal Device:

In Beeper, message @signalbot:beeper.local with link to get a QR code.

On your phone: Signal ➔ Settings ➔ Linked Devices ➔ Link New Device.

1
Enable & Start Discord Bridge Service:
sudo systemctl enable --now bbctl@sh-discord
2
Authenticate Discord:

In Beeper, message @discordbot:beeper.local with login-qr to scan the Discord QR code using your Discord mobile app.

1
Enable & Start Google Messages RCS Bridge:
sudo systemctl enable --now bbctl@sh-gmessages
2
Pair via Device Pairing:

In Beeper, message @gmessagesbot:beeper.local with login.

Open Google Messages on Android ➔ Profile icon ➔ Device pairing ➔ QR code scanner.

3 CLI Helper Reference (beeper / bbctl)

You can manage all bridges directly from your persistent tmux shell or SSH terminal:

beeper status
beeper logs sh-whatsapp
beeper restart sh-whatsapp
