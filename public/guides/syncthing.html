2 Desktop Client Setup (Linux, Windows, macOS)

Install and pair your laptop or desktop workstation with the server's shared folder:

sudo pacman -S syncthing systemctl --user enable --now syncthing

Access the client GUI locally at http://127.0.0.1:8384.

sudo apt update && sudo apt install -y syncthing systemctl --user enable --now syncthing

Access the client GUI locally at http://127.0.0.1:8384.

1
Add Server as Remote Device:

In client Syncthing GUI (bottom right), click Add Remote Device. Paste the Server Device ID, set Device Name to Tinarchy.

Under the Advanced tab: Set Compression to All Data.

2
Configure Shared Folder:

Click Add Folder in your client GUI:

• Folder Label: Shared

• Folder ID: shared (must match exactly!)

• Folder Path: Choose your local folder (e.g. /mnt/shared or ~/drive on Linux/Mac, or C:\Users\<user>\shared on Windows).

• Sharing Tab: Check the checkbox for Tinarchy.

• Advanced Tab: Set Compression to All Data.

3
Approve Pairing on Server:

Open the Server Syncthing GUI. Accept the incoming device prompt. The server will immediately link the shared folder with full end-to-end LZ4 block compression!

3 Mobile Client Setup (Android & iOS)

Sync your notes, wallpapers, photos, and files directly with your phone:

1
Install Syncthing-Fork:

Download Syncthing-Fork by Catfriend1 from Google Play Store or F-Droid (recommended over stock for modern Android scoped storage).

Grant All Files Access (Manage External Storage) when prompted so it can sync files outside the sandbox.

2
Add Server Device:

In Syncthing-Fork, tap Devices ➔ +. Paste the Server Device ID (or scan QR code). Set Name to Tinarchy.

Under Advanced, set Compression to All Data.

3
Add Shared Folder:

Tap Folders ➔ +:

• Folder ID: shared

• Folder Label: Shared

• Folder Directory: Select or create a folder on storage (e.g. /storage/emulated/0/Documents/shared or /storage/emulated/0/Shared).

• Share with Devices: Toggle Tinarchy to ON.

• Run Conditions (Optional): In app settings, enable "Sync only on Wi-Fi" or "Sync while charging" if you wish to strictly conserve battery.

1
Install Möbius Sync:

Download Möbius Sync from the Apple App Store.

2
Pair Device & Add Folder:

• Tap Devices ➔ + ➔ Paste Server Device ID ➔ Set Compression to All Data.

• Tap Folders ➔ + ➔ Set Folder ID to shared.

• Select storage path inside the app container or link to a folder in the Files app.

3
Access Files in iOS Files App:

Open the native iOS Files app ➔ browse to On My iPhone / iPad ➔ Möbius Sync. Your synced files (including Obsidian vaults, notes, and media) are instantly accessible to iOS apps!

4 Recommended Ignore Patterns (.stignore)

To avoid syncing operating system metadata, temporary cache files, and editor workspace layout locks, create a .stignore file in your drive folder with the following rules:

(?d)**/.obsidian/workspace.json (?d)**/.obsidian/workspace-mobile.json (?d)**/.obsidian/cache (?d)**/.trash (?d).DS_Store (?d)desktop.ini (?d)Thumbs.db (?d)*.tmp (?d)*.crdownload

5 Impenetrable Security & Isolation

🛡️ WireGuard Packet-Level Firewall: Syncthing ports (8384 Web GUI and 22000 BEP sync) are strictly bound to localhost and protected via Tailscale ACL rules. Guest accounts cannot establish sync connections.
🔑 Mutual Cryptographic Pairing: Every incoming connection is rejected unless explicitly approved with a verified Device ID fingerprint.
⚡ Hardware Accelerated LZ4 / Zstandard Compression: Data is compressed before being sent across the encrypted wire, maximizing sync speed over cellular or constrained networks.
