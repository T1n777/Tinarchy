2 Pair Your Main Laptop (Client)

1
Install Syncthing on Client Laptop:

• Arch / Omarchy Linux: sudo pacman -S syncthing then systemctl --user enable --now syncthing

• Ubuntu / Debian: sudo apt install syncthing

• Windows: Download SyncTrayzor or official installer from syncthing.net.

• macOS: brew install syncthing

2
Add tinarchy as a Remote Device:

Open Syncthing on your laptop (http://127.0.0.1:8384) ➔ Bottom right: click Add Remote Device ➔ Paste the Server Device ID from above ➔ Name it tinarchy ➔ Save.

3
Confirm Connection on tinarchy:

Open the tinarchy Web GUI. A prompt will appear stating your laptop wants to connect. Click Add Device.

4
Share Directory & Start Syncing:

In your laptop's GUI, click Add Folder (e.g. ~/Sync) ➔ Under the Sharing tab, check tinarchy ➔ Click Save.

On tinarchy, accept the shared folder and specify where to store it (e.g. /home/tin/Sync). Files will sync in real-time!

3 Impenetrable Guest Isolation

This service is strictly isolated so that only you (the Owner) can access it:

🛡️ WireGuard Packet-Level Firewall: Tailscale ACL rules strictly whitelist guests to ports 80, 443, 8080, 8081, and 4533. Any attempt by guest devices to connect to port 8384 (Web GUI) or 22000 (Sync) is instantly dropped by the kernel.
🔑 Mutual Cryptographic Pairing: Syncthing rejects any device that hasn't been explicitly paired with your personal Device ID.
👁️ Dashboard RBAC: The Syncthing management tile is completely hidden from guest accounts on the server dashboard.
