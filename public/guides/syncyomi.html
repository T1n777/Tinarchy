0 Install SyncYomi on Your Server (Optional)

If SyncYomi is not yet installed on this server, deploy it using the turnkey installer or package manager:

A
Automated Setup Script (Recommended):

Run the turnkey installer included in the repository:

sudo ./configs/scripts/install-syncyomi.sh

(If installed via AUR package: sudo /usr/share/tinarchy/configs/scripts/install-syncyomi.sh)

B
Package Managers:

• Arch / Omarchy Linux (AUR): yay -S syncyomi-git

• Debian / Ubuntu / Generic: Download the latest .deb or release binary from SyncYomi GitHub Releases.

C
Enable in Dashboard Environment:

In your server's .env file, set ENABLE_SYNCYOMI=true, then reload the dashboard:

sudo systemctl restart tinarchy.service

1 Create Account & Generate API Key

SyncYomi authenticates all readers via an API token. Generate one in the SyncYomi web dashboard:

1
Open Web GUI: Navigate to http://127.0.0.1:8282 and create your admin account on first launch.
2
Navigate to API Keys: Go to Settings ➔ API Keys ➔ click Add API Key.
3
Copy Token: Give it a name (e.g. MangaSync) and copy the generated token. You will use this token in both Suwayomi and Komikku.

2 Connect Suwayomi Server

Suwayomi-Server on Server has native SyncYomi client support built-in. Connect it using your API key:

# Add to /var/lib/suwayomi/.local/share/Tachidesk/server.conf: server.syncYomiEnabled = true server.syncYomiHost = "http://127.0.0.1:8282" server.syncYomiApiKey = "YOUR_API_KEY_HERE" server.syncInterval = "30m" server.syncDataManga = true server.syncDataChapters = true server.syncDataTracking = true server.syncDataHistory = true server.syncDataCategories = true

After editing, apply with: sudo systemctl restart suwayomi-server.service

3 Connect Komikku on Your Phone

Komikku includes native SyncYomi support out of the box. Follow these steps in the app:

1
Verify Tailscale: Ensure the Tailscale app is active on your phone so it can reach your private mesh network.
2
Open Sync Settings: In Komikku, tap More ➔ Settings ➔ Data and storage ➔ Sync service.
3
Select SyncYomi & Enter Server Address:

• Provider: SyncYomi

• Host: http://127.0.0.1:8282

• API Key: Paste the token generated in Step 1.

4
Trigger First Sync: Tap Sync now. Your reading status, read history, and manga bookmarks will now sync seamlessly with Suwayomi!

4 Security & Guest Isolation

• Tailscale WireGuard ACL: SyncYomi port is only accessible to authorized owner devices. Guest accounts are rejected at the kernel packet level.
• Token Authentication: Sync requests require the X-API-Token header.
• Local SQLite Storage: All synced manga metadata is stored in /var/lib/syncyomi/syncyomi.db with automatic rollback history.
