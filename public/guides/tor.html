1 Web Browser Configuration

You can route any web browser's traffic through this Tor proxy without installing the Tor browser:

🦊
Mozilla Firefox (Native Support):

1. Open Firefox Settings ➔ scroll to Network Settings ➔ click Settings...

2. Select Manual proxy configuration.

3. Set SOCKS Host: 100.67.207.60 and Port: 9050.

4. Check SOCKS v5 and Proxy DNS when using SOCKS v5 (prevents DNS leaks!).

🌐
Chrome / Brave / Edge (Extension):

Install the FoxyProxy Standard extension from the Chrome Web Store. Add a proxy with Protocol: SOCKS5, Host: 100.67.207.60, Port: 9050.

2 Terminal & Development Tools

Route command-line tools like curl, Python requests, or git through Tor:

A
Verify Tor Connection via cURL (Returns Exit Node IP):
curl --socks5-hostname 100.67.207.60:9050 https://check.torproject.org/api/ip
B
Route Current Shell Session Through Tor:
export ALL_PROXY="socks5h://100.67.207.60:9050" export HTTP_PROXY="socks5h://100.67.207.60:9050" export HTTPS_PROXY="socks5h://100.67.207.60:9050"
C
Git over Tor (Bypass ISP restrictions):
git config --global http.proxy 'socks5h://100.67.207.60:9050'
